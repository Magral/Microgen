# Этапы 7–8 · боссы и доводка

Основа — [дорожная карта](../../../ROADMAP.md). Версия 1.4 продолжает забег после победы и сохраняет совместимость с контрольными точками 1.3.

- [x] Замерить 1.3 по фиксированному десятиминутному сценарию. Упростить проверку проходимости `World.walkable` без изменения геометрии и повторить тот же сценарий. Сравнить время, память и состояние симуляции.
- [x] Связать процедурный тип босса с атакой, читаемым предупреждением, органом и периодом уязвимости. Показывать ту же атаку в разведке. Хранить состояние атаки в существующем сохранении врага.
- [x] Показать разрушение тела, закрепить за победой награду с постоянным органом или материалами и дать забрать её до смены области. Проверить сохранение результата при выходе и повторном входе.
- [x] Проверить симуляцию, бои, награды, сохранения и интерфейс. Повторить длительный замер кандидата, измерить сценарии боя с боссом и зафиксировать ограничения настольных измерений в [профиле](../../performance/1.4.0.md).
