# Адаптация интерфейса Defold — технический журнал

## Исходная версия

Работа ведётся от релиза Defold 1.5.7:

- Тег: `defold-1.5.7`
- Коммит: `95f1925571010b0b7ee552d387f5e41450c13e1b`
- Проект: `prototypes/defold`
- Базовая область GUI: 2460×1080
- Размер окна по умолчанию: 1230×540
- Ориентация: альбомная
- Минимальный Android API: 26
- Контрольное устройство: Poco X8 Pro

## Что обнаружено при аудите

- В `main/run/interface.lua` уже есть единая система координат, адаптация ширины панелей и подгонка текста.
- В `main/gameplay.gui_script` безопасные отступы применялись при построении HUD забега, но не распространялись автоматически на модальные окна.
- Прежний расчёт переводил все экранные отступы через один минимальный коэффициент. При независимом растяжении GUI по горизонтали и вертикали это может давать неверные значения по одной из осей.
- Большинство меню и модальных окон создаётся через общий модуль `Interface`. Это позволяет решать задачу централизованно, не переписывая каждый экран отдельно.

## Изменения в рабочей ветке

1. Добавлен `main/run/screen_layout.lua`. Он переводит отступы безопасной области из пикселей окна в координаты GUI отдельно по горизонтальной и вертикальной осям.
2. Добавлены числовые проверки для стандартного, широкого и более высокого альбомного профиля.
3. HUD использует новый расчёт безопасных границ.
4. В `Interface` добавлена настройка безопасной области: вычисляются доступная ширина/высота и центр рабочей зоны.
5. Общая компоновка панелей, текста, кнопок и карточек получает преобразование координат и размеров по двум осям. Для изображений сохраняются пропорции.
6. При открытии нового экрана безопасная область применяется к общему интерфейсу модальных окон.

## Ограничения проверки

- Числовые проверки модуля геометрии добавлены в режим smoke-запуска через параметр `microgen.smoke_run=1`.
- Наличие этих проверок ещё не означает, что они были выполнены в настоящей сборке: в рабочей среде пока не подтверждён запуск проекта Defold 1.5.7.
- Изменения не проверены на Poco X8 Pro и других физических Android-устройствах.
- Не проверены все экраны на эмуляторах с разными разрешениями и вырезами.
- Измерение FPS в этот этап не входит.

## Следующие шаги

1. Проверить компиляцию и запуск проекта Defold 1.5.7 с новыми изменениями.
2. Выполнить smoke-проверки и пройти все экраны: главное меню, создание семейства, организм, кодекс, наследие, награды, пауза, карта и переходы.
3. Проверить узкий, стандартный и широкий альбомные профили, а также разные высоты рабочей области.
4. Отдельно проверить кнопки закрытия, прокрутку, карточки, изображения и сенсорные области после масштабирования.
5. Провести практическую проверку на Poco X8 Pro.
6. После устранения найденных проблем добавить результаты проверки в этот документ и дорожную карту.

До прохождения этих шагов изменения считаются подготовленной реализацией в рабочей ветке, а не завершённой и проверенной адаптацией.
