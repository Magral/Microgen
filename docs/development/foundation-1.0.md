# Основа Микрогена 1.0

Релиз завершает первый этап дорожной карты: живой организм, читаемая сборка и наследие между забегами. Расширенная пищевая экосистема и новые масштабы мира остаются следующими этапами.

## Границы основы

| Часть | Реализовано и проверено |
| --- | --- |
| Организм | Процедурная форма, единая анимированная ткань, пасть, функциональные органы, повреждения, контактное переваривание и смешение пигментов |
| Забег | Процедурные области, миникарта, колонии, редкие цисты, минибоссы, рост и взаимодействия по размеру |
| Развитие | Качество и ранги органов, числовые сравнения, статистика сборки, три поведенческие эволюции: корона, мантия, утроба |
| Наследие | Три стартовые формы, три ветви исследований, два выбранных признака, один отпечаток, три набора и история 12 поколений |
| Интерфейс | Живой предпросмотр поколения, отдельный геном, крупные элементы, широкая прокрутка, крестики закрытия |
| Сохранения | Совместимость старого профиля, атомарная запись с проверкой временного файла, резервная копия, повторное завершение без двойных наград |
| Обновления | Явная проверка стабильного GitHub-релиза и его манифеста, скачивание через браузер |

Три остальных прежних рецепта эволюции пока дают числовой бонус к урону. Система не обещает новую поведенческую механику для каждого рецепта.

## Признаки и ограничения

| Признак | Преимущество | Ограничение |
| --- | --- | --- |
| Эластичность | Отклик движения 0,13 вместо 0,20 секунды | +8% получаемого контактного урона |
| Чувствительность | Обнаружение ценных находок 400 вместо 240 | −5% скорости |
| Складки | −20% времени переваривания отделённых частей | −10% получаемого лечения |
| Восприимчивость | Вес предложений своей ветви 1,75 вместо 1,35 | −5% опыта |

Отпечаток органа начинает с обычного ранга 1, без прежнего качества и эволюции. Отпечаток тела может добавить третий эффективный признак через отдельное место наследия. Передаются происхождение, часть оттенка и рисунок ткани; дальнейший цвет меняется от пищи.

## Защита прогресса

Ожидает один выбор и до восьми следующих результатов. Заполненная очередь блокирует новый старт. Если текущая жизнь закончилась при полной очереди, её завершённый снимок сохраняется: после освобождения места итоги можно зачислить. Перезапуск и переход через меню не заменяют этот снимок новым забегом. У повторного завершения нет повторной выдачи ядер.

Исследования, выбор формы, признаки, отпечатки и наборы записываются атомарно. Ошибка записи не должна изменять живой профиль или разрушать последнюю исправную резервную копию.

## Проверки перед публикацией

- Полный `ci/run_tests.py`: модели, симуляция, сохранения, наследие, интерфейс, награды, обновления, восстановление итогов, native touch и графические проверки — без ошибок.
- Шесть тестов импортёра исходников — без ошибок.
- Нативные снимки нового поколения, генома и отпечатков просмотрены; новые окна имеют закрытие и широкую прокрутку.
- Десятиминутный повтор и парное профилирование относительно 0.11.0: [результаты](../performance/1.0.0.md). Общего ускорения замеры не подтверждают.
- Проверка кода и исправление найденных проблем сохранений, очереди, пресетов, кэша внешности и восстановления итогов.
- Последний обязательный шлюз выполняется GitHub Actions: повтор тестов, release APK, отсутствие debug-флага, версия 1.0.0/code 100, прежний сертификат и разрешения. Публикация запускается только после этих проверок.

## Android и обновление

Сохраняются `org.magral.microgen` и сертификат прежних выпусков, чтобы обновляться поверх установленной игры. Используется существующий development keystore репозитория; это совместимость подписи, а не переход на новый закрытый production-ключ.

Игра не устанавливает APK самостоятельно и не проверяет хеш скачанного браузером файла. Проверяется манифест, версия и адрес ассета GitHub; фактический размер и SHA256 APK публикуются сборкой. Установку подтверждает пользователь в Android. Подробнее: [обновления](updates.md).

Физический Android в среде разработки недоступен. Автоматические проверки и настольный профиль не заменяют проверку плавности, звука и сохранения данных после обновления на Tecno POVA 5. Видео не создаются.
