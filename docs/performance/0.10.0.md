# Данные профилирования версии 0.10.0

Измерено 17 ноября 2026 года относительно неизменяемого коммита версии 0.9.0 ec09c90de394d2dd01c4c7f40b52f6253339ab83. Кандидат — замороженная копия объединённой симуляции/отрисовщика мира версии 0.10.0 до последующих уточнений текста инспектора/меню, компоновки и размещения индикаторов. Код инспектора/меню исключён из этих тестов; изменения расположения индикаторов сохраняют тот же бюджет отрисовки. Рабочие исходники не инструментировались.

## Результат и ограничения

В выпуск добавлены атрибуция боевого урона, цисты наград, визуальные сигналы взаимодействия/повреждения, а также кэшированные рецепты органов врагов, общие позиции клонов на один проход отрисовки и кэшированные синергии сборки. Измерения показывают дополнительную стоимость симуляции и неоднозначные результаты нативных сцен. Они **не доказывают общего повышения производительности**. В замороженной сцене с лимитами CPU отрисовки вырос на 1,9%, медиана полного кадра — на 4,3%; p95 в этом одном прогоне ниже.

Godot 4.6.3; 1280×720; GL Compatibility; запрошенное отключение VSync не поддерживается этим драйвером; частота кадров движка не ограничена; Xorg dummy; Mesa 25.0.7 llvmpipe, программный рендеринг LLVM 19.1.7. Полное время кадра включает жидкость, оптические плоскости, шейдеры и растеризацию драйвера/программы. CPU отрисовки не включает стоимость шейдеров/растеризации. HUD, мини-карта, меню развития/наград и сведение аудио исключены. Это счётчики программного рендерера, **не измерения FPS Android или аппаратного GPU**. Каждая нагрузка — одна последовательная пара на одной машине с обычной дисперсией планировщика/растеризации. Headless-повтор кандидата кратковременно пересекался с отдельной визуальной проверкой QA; поэтому его время также имеет это ограничение планирования. Нативные базовый и кандидатный прогоны выполнялись без другой активной нативной QA.

## Повторение и данные

Команды запуска из корня репозитория:

    python tools/performance/run_profile.py --commit ec09c90 --output build/performance-010-baseline --native
    python tools/performance/run_profile.py --source build/performance-010-candidate-source --output build/performance-010-current
    python tools/performance/run_profile.py --source build/performance-010-candidate-source --output build/performance-010-current --snapshots build/performance-010-baseline --render-only --native

Перед запуском кандидата исходники фиксируются в build/performance-010-candidate-source. Копия исходников исключает .git, .godot, build и ZIP-файлы. Сырые журналы повтора/нативного/ограниченного прогона, контрольные точки и извлечённый JSON остаются в двух каталогах результатов. build/performance-010-report.json объединяет оба полных набора результатов, количество контрольных точек ограниченного состояния, число ошибок и все 36 хэшей SHA256 производственных исходников. Манифест исходников: build/performance-010-candidate-source/profile-source-hashes.json. Видеоролики не записывались.

Повторный прогон — 36 000 шагов с частотой 1/60 (десять симулируемых минут), seed 44, шесть обычных органов ранга 3/четыре адаптации ранга 3, высокое здоровье, отключённый только для профилирования босс и смена направления движения каждые шесть симулируемых секунд. Ожидающие повышения уровня очищаются, очереди событий UI/аудио обрабатываются на каждом шаге. Выбор наград не подтверждается; качество/эволюция не применяются. Этот сценарий не измеряет сборки с улучшенным качеством/эволюцией или взаимодействие с меню.

Обе нативные версии восстанавливают одни и те же базовые контрольные точки 0/180/360/600. Для каждой выполняются 60 прогревочных кадров и 180 измерений отрисовки, пока симуляция продолжается с фиксированной частотой 1/60. Отсутствующие эффекты создаются заново во время прогрева; следы воды зависят от реальной длительности кадра. Число врагов, полей, останков и эффектов на измеренных конечных точках совпадает, но это сравнение парных начальных сцен, а не замороженные идентичные кадры. Холодное создание ландшафта/кэша не входит в прогретое измерение.

История боя ограничена 32 записями, агрегация источников — 32 именованными группами плюс группа переполнения, метки урона — шестью, защитный лимит цист — 12; за забег создаётся не более шести маркеров наград карты/двух наград элитных врагов. В сценарии остаются три награды в очереди. Повторный выбор наград не проверяется. Существующие лимиты сцены сохраняются: 28 врагов/96 останков. Рецепты органов врагов кэшируются по идентичности и сигнатуре вида/варианта/признаков, очищаются по списку живых врагов, сбрасываются при смене симуляции и принудительно очищаются при размере более 256 записей. Позиции клонов вычисляются один раз за отрисовку мира и используются общими эффектами; синергии пересобираются только при изменении хэша публичных словарей органов/адаптаций. Эти решения сокращают повторные вычисления, но приведённые времена пакета включают новую работу и не выделяют ускорение от одного кэша.

Аудио использует 11 предварительно вычисленных PCM-сэмплов, шесть голосов событий и один постоянный голос цикла движения. Движение меняет громкость/высоту тона, а не синтезирует/перезапускает сэмплы каждый кадр; воспроизведение событий глобально ограничено одним срабатыванием на 0,4 с, дополнительно действуют интервалы для каждого типа. Это ограничение ресурсов на уровне исходного кода; профильный стенд обрабатывает обратную связь без сведения звука, поэтому не делает выводов о CPU аудио или субъективном качестве звука.
