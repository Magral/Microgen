# Сравнение производительности версии 0.11.0

Измерено 17 ноября 2026 года по UTC (18 ноября в часовом поясе пользователя). База — неизменяемая версия 0.10.0 fe3c9f4bd4a79bc7520c44396649cce765c60d5b. Кандидат — временная замороженная копия рабочих исходников, созданная профильным запуском до последующих изменений компоновки управления наградами, фикстуры снимков и документации; эти изменения UI/фикстур не входят в профильный стенд.

## Изменения и ограничения

Конкретные оптимизации: повторное использование поз кормления, подготовленных для физики контакта, вместо повторного построения при отрисовке; кэш объединённых органов/адаптаций игрока по хэшу содержимого; один поиск опор контура для редкого участка мембраны вместо семи; кэширование кадров раскрытия вместо выделения ресурсов стиля при каждой перерисовке. Новая визуальная работа включает анимированные железы, более явное заражение, удары каждой конечностью, метки лечения и признаки редкой ткани.

Это НЕ доказательство общего ускорения. Времена нативных сцен смешанные и в основном выше по мере усложнения визуала. В одинаковой насыщенной сцене медианное время отрисовки/полного кадра немного ниже, но одна пара не позволяет отличить это от разброса планирования. Заявлений о FPS Android нет.

Godot 4.6.3, 1280×720, GL Compatibility, Xorg dummy через TCP, программный рендеринг Mesa llvmpipe, частота движка не ограничена; отключение VSync запрошено, но драйвер не поддерживает. Нативные нагрузки базы и кандидата запускались последовательно, без другой активной нативной QA. Короткие headless-регрессионные проверки выполнялись во время части профилирования базы/кандидата; учитывайте это ограничение планирования при интерпретации CPU-времени. HUD, сведение аудио, меню наград и лист всех навыков не входят в профильный стенд.

## Повторение и данные

    python3 tools/performance/run_profile.py --commit fe3c9f4bd4a79bc7520c44396649cce765c60d5b --output build/performance-011-baseline --native
    python3 tools/performance/run_profile.py --output build/performance-011-current --snapshots build/performance-011-baseline --native

Профильный запуск инструментирует временные копии; производственные исходники остаются без инструментирования. Сырые журналы и состояния повтора находятся в двух каталогах результатов. build/performance-011-report.json содержит все измерения и хэши SHA256 исходников. Видеоролики не создавались.

## Десятиминутный повторный прогон

36 000 фиксированных шагов по 1/60, seed 44, шесть органов ранга 3/четыре адаптации ранга 3, большое здоровье, отключённый босс, смена направления каждые шесть симулируемых секунд, очистка ожидающих повышений и обработка обратной связи каждый кадр. Теперь щупальца распределяют тот же общий залп по нескольким врагам; выбор целей меняет смерти, выпадения, расход RNG и последующие популяции. Это сравнение длительности/ресурсов, а НЕ оптимизация при идентичной нагрузке. Кандидат завершает 221 убийством против 176; темп боя с одной целью проверяется отдельно.
