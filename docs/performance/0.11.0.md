# 0.11.0 performance comparison

Measured 17 November 2026 UTC (18 November in Pavel's timezone). Baseline is immutable 0.10.0 `fe3c9f4bd4a79bc7520c44396649cce765c60d5b`. Candidate is a disposable frozen working-source copy created by the profile runner before later reward-control layout, screenshot-fixture and documentation refinements; those UI/fixture changes are outside the profile harness.

## Changes and limitations

Concrete optimizations: reuse feeding poses prepared for contact physics instead of constructing them again during draw; cache merged player organs/adaptations by content hash; one contour-anchor search per rare membrane patch instead of seven; cache reveal frames rather than allocate style resources each redraw. New visual work includes animated glands, more explicit infection, per-limb strikes, healing labels and rare tissue marks.

This is NOT evidence of an overall speedup. Native scene timings are mixed and mostly slower as visuals increase. The equal saturated scene has slightly lower median draw/full-frame times, but one pair cannot distinguish that from scheduling variance. No Android FPS claim is made.

Godot 4.6.3, 1280×720, GL compatibility, Xorg dummy over TCP, Mesa llvmpipe software rendering, uncapped engine; requested VSync-off unsupported by driver. Baseline and candidate native workloads were sequential, with other native QA idle. Short headless regression checks occurred during some baseline/candidate profiling; interpret CPU timings with that scheduling limitation. HUD, audio mixing, reward menus and the all-skills sheet are outside the profile harness.

## Reproduction and evidence

```sh
python3 tools/performance/run_profile.py --commit fe3c9f4bd4a79bc7520c44396649cce765c60d5b --output build/performance-011-baseline --native
python3 tools/performance/run_profile.py --output build/performance-011-current --snapshots build/performance-011-baseline --native
```

The runner instruments disposable copies; production sources stay uninstrumented. Raw logs and replay states are in the two output directories. `build/performance-011-report.json` contains all readings and source SHA256 values. No videos.

## Ten-minute replay

36,000 fixed 1/60 steps, seed 44, six rank-3 organs/four rank-3 adaptations, large HP, boss suppressed, movement changes every six simulated seconds, pending levels cleared and feedback consumed every frame. Tentacles now distribute the same total volley among multiple foes; target selection changes deaths, drops, RNG consumption and later populations. This is a longevity/resource comparison, NOT an identical-workload optimization comparison. Candidate finishes 221 kills versus 176; isolated single-foe combat pacing is tested separately.
