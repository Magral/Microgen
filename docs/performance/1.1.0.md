# Проверки производительности и стабильности версии 1.1.0

Измерено 18 ноября 2026 года. Неизменяемая база: стабильная 1.0.1 b40c34e93dcba35a7fda0cea181c84803489e7ae. Кандидат: замороженные подготовительные копии release/1.1.0. Итоговый нативный проход включает исправленную ленточную сетку щупалец. Последующие изменения проекции активного состояния/страниц UI не влияют на игровой профильный стенд отрисовки.

Godot 4.6.3, GL Compatibility, 1280×720, Xorg dummy, программный рендерер Mesa llvmpipe; VSync-off не поддерживается. Нативные прогоны выполнялись последовательно. Короткие headless-проверки, проверка файлов и работа с документацией пересекались с некоторыми измерениями. Одна пара не может доказать общего ускорения. Это результаты настольного программного рендеринга, **не FPS Android**. HUD/аудио/автоматические сохранения контроллера и меню не входят в игровой профильный стенд. Расширенные камеры тела ограничены шестью видимыми пузырьками, но сцена с их максимальной стоимостью отдельно не профилировалась.

## Что изменилось

- Проекция активного состояния копирует только активные поля, вместо того чтобы сначала копировать каждое архивное семейство, а затем удалять эту копию. Сохранение по-прежнему проверяет все записи семейств и сохраняет проверенную резервную копию; большие коллекции имеют измеримую стоимость записи.
- Страницы тела создают не более восьми ячеек вместо выделения каждой пустой ячейки до полной вместимости. Страницы запаса создают не более трёх позиций. Фикстура границы в миллиард ячеек открывает последнюю страницу, не создавая промежуточные.
- Щупальца используют фиксированную ленту из 17 треугольников с тем же сужающимся контуром. Удар назад может схлопнуть ось полигона; старая триангуляция контура не проходила для этой позы. Нативная регрессионная проверка и 22 816 математических поз проходят. Лимиты числа органов, разрешение контура, врагов или эффектов не уменьшались.
- Профильный запуск теперь отклоняет журналы с ERROR/SCRIPT ERROR, даже если Godot завершился с кодом 0. Первоначальный нативный проход кандидата выявил ошибку щупальца и исключён из таблицы нативных результатов ниже; повторные итоговые нативные журналы чистые.

## Стоимость сохранения семейств

Двенадцать проверенных сохранений и двенадцать выборов семейства для каждого размера; репрезентативные новые живые контрольные точки. Запуск движка и создание семейства исключены. Проверка сохранения/резервная копия остаются включёнными. Выбор того же семейства — пустая операция в строке с одним семейством. На более медленной файловой системе/телефоне или при большей контрольной точке стоимость может быть выше.

Медиана записи десяти семейств изменилась с 89,788 до 84,006 мс в этой паре, тогда как строка для пяти семейств стала медленнее. Изменение проекции убирает ненужное копирование, но эта пара не обосновывает общее заявление об улучшении времени. Автосохранение происходит каждые 12 секунд; большие коллекции семейств всё ещё могут вызывать заметную задержку записи. Разделение хранилища или фоновая сериализация потребуют отдельной работы над миграцией/восстановлением.
