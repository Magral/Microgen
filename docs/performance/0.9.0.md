# 0.9.0 performance evidence

Measured November 17, 2026. Baseline is immutable `ef9807e74fc5dd64d04f0c93e5f0a3881d91767d` (0.8.0); the four-scene candidate is the optimized aquatic/organic-volume working tree before the final wall-gradient refinement with safe irregular membrane triangulation, cached species density, six-bit material LUT, and batched substrate meshes. Source hashes appear below.

## Result and limits

The richer visuals add measurable cost against 0.8.0. Every measured saved scene has higher CPU draw construction and higher full-frame median. This release includes specific bounded-work optimizations, but these measurements **do not establish an overall performance improvement**. The ten-minute simulation preserves exact gameplay populations and shows broadly bounded sampled memory. Native renderer memory increases with the new cached geometry/materials; this short scene benchmark does not establish long-session renderer memory behavior.

Native frame wall includes water, foreground optical planes, shader execution and driver/software rasterization. World-view CPU section counters exclude fluid draw and shader cost. Measurements use Godot 4.6.3, 1280×720, GL compatibility, requested VSync off (unsupported by this driver), uncapped engine, Xorg dummy, Mesa 25.0.7 llvmpipe LLVM19.1.7 software rendering. HUD/minimap/audio mixing are excluded. No desktop/mobile/Android FPS claim follows. Each table is one sequential same-machine run; CPU scheduling, software rasterization, and wake decay introduce variance.

A supplemental disposable-copy fixture draws only water at 1280×720: seed 44, clock 12 s, 100 particles, 96 fixed wakes, stationary camera, simulation paused, 60 warmup+180 draw samples. ## Optimization scope and remaining cost

Organic volume caches topology, up to 48 quantized material palettes and fixed species density instead of rebuilding lighting/density calculations per creature per frame. Nonradial damaged contours use safe polygon triangulation. Additional contour vertices/colors and membrane shading still increase CPU construction. The pre-wall renderer records its 21,763 terrain recipe commands once (seed 108 full-map regression fixture), then bakes polygons/circles/feathered strokes into one indexed native call per nonempty visible 6×6 tile patch. The 52×38 map has 63 patches. This bounds submission count while preserving substrate detail; baked geometry still consumes memory and raster work. Warmed terrain update is separately reported in raw JSON; cold first-build/setup cost is outside the warmed comparison.
