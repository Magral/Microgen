# 0.8.0 long-run performance evidence

Baseline: git commit `64a50cb` (0.7.0). Candidate: 0.8 working tree with terrain/minimap caching, radius caching, wound polygon repair, bounded visual recipes, rank milestones, vivid synergy effects, exact radial mouth lookup, and per-paint normalized anatomy anchors. Measurements taken November 17, 2026. Candidate source was copied after the final mouth/anchor and field/infection performance passes; originals were never instrumented.

## Result and limits

The actual ten-minute replay reproduces initial scene growth and rising simulation work, then broadly bounded populations rather than a memory leak. Late-run CPU draw cost is strongly scene-dependent: nearby damaged/infected enemy anatomy dominates. The 600-second snapshot remains heavier than the starting scene after this patch. This work improves the measured burden; it does not establish that long-session performance is fully solved or promise desktop/mobile FPS.

All native effects remained enabled. Candidate native snapshot and capped-scene runs contain **zero errors**. Baseline snapshot run logged 1279 invalid wound-polygon triangulation errors; candidate logged 0. Capped baseline had 0 errors. Existing baseline checkpoint decoding omitted enemy `impulse` reconstruction; profiling repaired it in the harness, and production now decodes it.

## Reproduction

See [runner instructions](../../tools/performance/README.md). From repository root:

```sh
python tools/performance/run_profile.py --commit 64a50cb --output /tmp/microgen-baseline --native
python tools/performance/run_profile.py --output /tmp/microgen-current --snapshots /tmp/microgen-baseline --native
```

Actual replay:36,000 steps at 1/60 second, seed 44, six rank 3 organs and four rank 3 adaptations, high HP, boss spawn disabled only for profiling, movement changes each 6 simulated seconds, event queues consumed. Reports at 0/180/360/540/600 seconds; exact stage counters and collection sizes follow below. Native runs use the **same baseline 0/180/360/600 snapshots** for both versions,60 warmup plus 180 draw measurements perstage. Simulation continues at 1/60; errors and all world effects remain enabled. Effects are not checkpointed, so they rebuild during warmup. Snapshot sources are identical; candidate combat can diverge slightly while continuing because rank 3 milestones increase damage.

Native environment: Godot 4.6.3,1280×720, GL compatibility, requested VSync off, engine maxfps 0; Xorg dummy driver, Mesa 25.0.7 llvmpipe LLVM 19.1.7 (software rendering). **CPU draw construction timings below are not a user's desktop FPS.** Full frame timings in raw JSON include software raster/shader/driver overhead and should not be generalized. World benchmark excludes HUD/minimap and audio mixing; minimap caching is therefore not measured here. Cached terrain setup is warmed before measurement.
