# Сборка в GitHub Actions

Workflow запускается при изменениях main, pull request, теге v* и вручную.
Пока исходников нет, выполняются проверки импортёра и выводится ожидание архива.

Первый перенос: загрузить Microgen-0.1.0-source.zip в корень main через интерфейс GitHub.
Архив импортируется один раз; существующий project.godot не перезаписывается.
Файлы CI и workflows из архива не импортируются. Тестовый development.keystore сохраняется.

После импорта: Godot 4.6.3, проверки логики и касаний, APK arm64, проверка подписи,
SHA256SUMS.txt, архив исходников и тестовый релиз. Точный SHA исходников записан в build/SOURCE_COMMIT.txt.
Физический Android-телефон этим workflow не проверяется.

Изменения 0.2.0 пока не восстановлены из прежней недоступной среды.
Сборка базовой 0.1.0 не означает, что процедурная внешность 0.2.0 уже перенесена.
