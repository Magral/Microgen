# Сборка Android

> Эта запись описывает прежний процесс сборки прототипа и не является действующей инструкцией для принятой версии Microgen на Defold.

Историческая процедура восстанавливала исходники из сохранённого архива 0.1.0, отдельно восстанавливала изменения 0.2.0, запускала тесты логики, сохранений, геометрии и сенсорного ввода, затем формировала кадры игры/коллекции и подписанный тестовый APK.

Эта процедура не подтверждает сборку проекта Defold 1.5.7 и не должна использоваться как актуальный путь выпуска. Принятый проект находится в каталоге `prototypes/defold`; его следует открывать через `prototypes/defold/game.project` в Defold Editor.

Физическое Android-устройство в прежней автоматизированной процедуре не проверялось. Проверка на Poco X8 Pro и других устройствах выполняется отдельно.
