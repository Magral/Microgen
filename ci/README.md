# Сборка APK

Базовые исходники восстановлены из сохранённого архива 0.1.0.
Изменения 0.2.0 восстановлены отдельно и проверяются новым запуском.

Сборка устанавливает официальный Godot 4.6.3 с проверкой SHA-256, Java17 и Android SDK.
Выполняются тесты логики, сохранений, геометрии и сенсорного ввода, затем создаются реальные кадры игры/коллекции и подписанный тестовый APK.
APK, исходники и контрольные суммы доступны в Actions и тестовых Releases.
Физический телефон в этой процедуре не проверяется.
