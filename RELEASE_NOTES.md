# Microgen · Defold 1.5.12

Выпуск для Android ARM64. Код версии Android: 162. Пакет: `org.magral.microgen.defold`. Минимальная версия Android: API 26.

## Что изменилось

- Снижен контактный урон крупных обычных амёб: до 25% в зависимости от отношения размеров. Урон мини-боссов и боссов не изменён.
- При перекрытии ядовитых облаков одного противника действует только наиболее сильное из них; урон от разных источников остаётся независимым.
- Сохранено исходное число копий органа «Деление» (2–5 без специализации): экспериментальное увеличение отменено по результатам сравнительных забегов.
- При восстановлении забега сохраняются фаза укуса и время последнего предупреждения об опасности. Проверяется восстановление боя во время подготовки выстрела.
- Усилены автоматические проверки сохранений: отказ записи, откат к предыдущей ревизии, изоляция семей и защита от повторного начисления награды.
- Автообновление игнорирует некорректные записи о файлах, очищает устаревшие метаданные и разрешает запуск установщика только после готовности проверенного APK.
- CI сравнивает три стартовые формы на шести общих картах (18 автозабегов), а проверки разных коммитов рабочей ветки не отменяют друг друга.

## Обновление и проверки

- Код версии повышен с 161 до 162; пакет, ключ подписи в конвейере и формат сохранений не изменены.
- Релизный CI проверяет сборку, подпись, идентификатор APK, четыре альбомных профиля, сценарии восстановления сохранений и автообновления.
- Практическую проверку обновления с 1.5.11, сохранения семей и баланса на Poco X8 Pro следует выполнить после публикации. Автозабеги не заменяют живое тестирование.
