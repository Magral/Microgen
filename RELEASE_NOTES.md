# Микроген 1.0.1 · Главное меню и отрисовка

- Главный экран больше не прокручивается. Продолжение забега, новый организм, геном, атлас, помощь, обновления, коллекция, ожидающее наследие и выход помещаются на экране одновременно.
- Убрано большое модальное окно начального меню: фон микромира занимает весь экран, кнопки размещены поверх него.
- Оптимизирован расчёт объёмной ткани: координаты строятся нативными преобразованиями массивов, освещение повторно используется при неизменных нормалях и материале. Кэш ограничен 96 записями.
- Сохранены палитра, повреждения, желейная деформация и функциональные органы. Баланс и формат сохранений не менялись.

Сравнение с 1.0 и ограничения измерений: docs/performance/1.0.1.md. Настольный программный рендерер не показывает Android FPS; физический телефон в среде разработки недоступен.

Версия Android 1.0.1/code101. Прежние package name и подпись сохранены: устанавливайте APK поверх старой игры. Проверка обновлений остаётся явной, скачивание открывается в браузере, установку подтверждает пользователь в Android. Видеоролики не создавались.
