# Microgen · Defold 1.5.8

**Статус:** стабильный релиз опубликован 24 ноября 2026 года
**Движок:** Defold
**Android version code:** 158
**Архитектура:** ARM64 (`arm64-v8a`)
**Идентификатор приложения:** `org.magral.microgen.defold`
**Минимальная версия Android:** API 26
**Ориентация:** альбомная

## Изменения

- Добавлен общий расчёт безопасной области экрана, применяемый к HUD и модальным интерфейсам.
- Расширена автоматическая проверка альбомных размеров экрана.
- Усилены регрессионные проверки распада, останков, поглощения и повторного использования визуальных слотов.

## Проверки и совместимость

- Android ARM64 APK собран; подпись и идентификатор приложения проверены.
- Linux smoke-проверки прошли на четырёх альбомных профилях.
- Идентификатор пакета, минимальная версия Android и формат сохранений сохранены.
- Практическая установка на Poco X8 Pro и полный переход обновления 1.5.7 → 1.5.8 не подтверждены в доступных результатах; их нельзя считать выполненными.
