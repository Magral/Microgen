# Микроген 1.3.0 · Лестница миров

Выпуск закрывает этапы 5–6 дорожной карты. Забег теперь проходит через процедурно создаваемые области: после победы над боссом амёба продолжает путь, получает награду и готовится к следующей угрозе.

## Что нового

- **Непрерывный забег.** Победа над главным боссом открывает переход на следующую ступень, не заканчивая жизнь. Положение на лестнице, босс-победа и ожидающая область сохраняются в контрольной точке.
- **Боссы по этапам исследования.** Сначала нужно открыть гнёзда и победить местных минибоссов; затем появляется отметка главного босса. Таймер больше не вызывает финального босса.
- **Разгон знакомого маршрута.** Рекорд лестницы сохраняется в профиле. На уже пройденной ступени достаточно одного минибосса вместо двух.
- **Разведка перед входом.** Короткая пропускаемая анимация показывает сгенерированную область, миникарту с цистами трёх качеств, условия среды, цель этапа, имя/здоровье босса и подсказку по синергии.
- **Платная полная смена области.** Новая область перебрасывается целиком за органиум; цена зависит от ступени. После подтверждения сохраняются новая генерация и списанный ресурс.
- **Продолжение развития.** Победа даёт ядра наследия и ценный ресурс, после чего открывается окно подготовки и игрок возвращается к своему организму.
- **Чище экран тела.** Орган показывается один раз с рангом и занятыми клетками; общая шкала вместимости заменяет повторяющиеся карточки каждой ячейки.
- **Понятнее выбор уровня.** Повтор органа растёт сильнее по качеству находки. Карточки короче, с более крупным названием и числовым изменением; на узком экране выбор листается по одной карточке.
- **Явнее синергии.** Возможная пара помечается до выбора, а срабатывание получает собственное окно и цветные пульсирующие узлы на мембране.
- **Экономия генерации этапа.** Сгенерированный для миникарты объект мира переиспользуется при входе в эту область. Вместо повторной генерации одного и того же seed область строится один раз.
- **Сохранения 1.2.0 совместимы.** Для старых профилей рекорд лестницы и поля новой контрольной точки получают безопасные значения по умолчанию.

Android APK: version code 130, package `org.magral.microgen`, прежняя подпись для установки поверх 1.2.0. Обновление устанавливается штатным подтверждением Android. Видео в выпуск не включается.

Парное десятиминутное измерение 1.2.0 и 1.3.0 и его ограничения опубликованы в [профиле производительности](docs/performance/1.3.0.md). Это настольный GDScript-профиль, а не обещание FPS на Android. Статус CI, APK, подпись, скриншоты и контрольные суммы добавляются после прохождения workflow выпуска.
