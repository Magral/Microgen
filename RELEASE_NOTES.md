# Микроген 1.2.0 · Органы и добыча

Выпуск закрывает этапы 3–4 дорожной карты. Один организм-наследник развивается между забегами: найденные органы сохраняются, постоянно улучшаются, специализируются или расщепляются на ингредиенты. Внутри жизни добавлены временные мутации и безопасная очередь находок при заполненном запасе.

## Что нового

- **Бесконечное развитие органов.** У каждого экземпляра свой постоянный ранг, качество и специализация. Следующая цена растёт; вклад ранга в боевые параметры постепенно убывает и остаётся ограниченным, чтобы поздние уровни не ломали баланс и сохранение.
- **Специализации органов.** Каждый вид органа получил два направления с разными боевыми эффектами и анатомическими знаками. Смена стоит семейный ресурс и не сбрасывает вложенный ранг.
- **Расщепление с возвратом материалов.** Ненужный орган можно разобрать за ингредиенты для развития других. До подтверждения показан точный возврат.
- **Мутации текущей жизни.** Шесть временных вариантов меняют боевые показатели до завершения забега, сохраняются в живой контрольной точке и сбрасываются со смертью.
- **Находки не теряются при заполненном запасе.** Полученный орган ставится в очередь. Игра открывает короткое окно, где его можно установить, расщепить или отложить в архив.
- **Короткие карточки и отдельный Кодекс.** На карточках остаются название, редкость и главные числа; подробные эффекты, специализации и синергии вынесены в Кодекс с короткими страницами.
- **Совместимость с 1.1.0.** Старые семейства, органы и незаконченные живые забеги загружаются с безопасными значениями по умолчанию.
- **Оптимизация частого пути.** Расчёт силы сборки пропускает вычисления рангов и временных эффектов для обычных органов без этих модификаторов; художник тела больше не ищет специализацию для каждого пустого органа. Замеры и ограничения приведены в [профиле 1.2.0](docs/performance/1.2.0.md).

Android APK: version code 120, package `org.magral.microgen`, прежняя подпись для установки поверх предыдущей сборки. Обновление можно проверить вручную; Android отдельно подтверждает установку. Видео не создавались.

Проверки: полный локальный сценарий CI, нативные касания, старые и новые контрольные точки, миграция сохранений, интерфейс и скриншоты выполнены. Сборка APK и подпись выполняются GitHub Actions перед публикацией. В этой среде нет Android SDK и физического телефона; настольные CPU/рендер-замеры не являются показателем FPS на Android.
