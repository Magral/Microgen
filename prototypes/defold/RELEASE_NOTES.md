# Microgen · Defold 1.5.10

**Статус:** стабильный выпуск 1.5.10 публикуется автоматически после успешного CI
**Движок:** Defold
**Android version code:** 160
**Архитектура:** ARM64 (`arm64-v8a`)
**Идентификатор приложения:** `org.magral.microgen.defold`
**Минимальная версия Android:** API 26
**Ориентация:** альбомная

## Изменения

- По выбору пользователя концепция «бирюзовая амёба с сияющим ядром» назначена иконкой Android для шести плотностей экрана.
- Карточки синергий показывают игровой эффект, необходимые органы и состояние активации.
- Плюющаяся амёба фиксирует направление и показывает кислотно-зелёный сигнал за 0,65 секунды до выстрела.
- Автоматические проверки подтверждают численные эффекты органов и видимость сигнала противника на четырёх экранных профилях.

## Совместимость и автообновление

- Версия повышена с 1.5.9 / 159 до 1.5.10 / 160 для штатного обновления Android.
- Сохранены идентификатор пакета `org.magral.microgen.defold`, минимальный API 26 и формат сохранений.
- Автообновитель Defold выбирает стабильный APK версии 1.5.10 из опубликованных релизов; CI проверяет переход 1.5.9 → 1.5.10 и имя, адрес, размер и SHA-256 APK.
- Установка и обновление с сохранением прогресса на Poco X8 Pro остаются пользовательской проверкой после публикации.

## Проверки

- Android ARM64 сборка, подпись, идентификатор приложения и Linux smoke на четырёх профилях должны пройти в релизном GitHub Actions запуске до публикации.
- Сравнение длительной нагрузки между версиями не проводилось.

APK и контрольная сумма будут доступны на [странице стабильного релиза](https://github.com/Magral/Microgen/releases/tag/defold-1.5.10).
