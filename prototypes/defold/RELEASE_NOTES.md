**Статус:** стабильная публикация запускается после успешной сборки этого кандидата

**Архитектура:** ARM64 (`arm64-v8a`)

**Ориентация:** альбомная

## Изменения

- Удалён повторяющийся сетчатый узор, который мог проявляться на поверхности мембраны.
- Край информационного блока игрового HUD выровнен по левому краю сцены; внутренние отступы содержимого сохранены.
- Улучшены адаптация безопасных областей, управление одним пальцем и работа на четырёх альбомных профилях.
- Добавлены мягкое дыхание организмов, изгиб и поворот ткани при поглощении.
- Реакция мембраны на урон дополнена короткой волной со стороны источника удара.
- Усилены автоматические проверки геометрии, сенсорных зон, поглощения, повреждения ткани и жизненного цикла останков.

## Совместимость

- Пакет остаётся `org.magral.microgen.defold`, минимальная версия Android — API 26.

- Формат сохранений, баланс и правила боя в этом выпуске не менялись.
