## Микроген 0.4.0 · Defold

- Игра проверяет стабильные выпуски Defold в фоне и загружает APK в кэш приложения.
- Перед запуском установщика проверяются размер, SHA-256, идентификатор Android-пакета, номер сборки и подпись.
- Установщик открывается в главном меню или на экране обновлений. Первую установку из игры может потребоваться разрешить в настройках Android. Android просит подтвердить обновление.
- Сборка распространяется через GitHub Releases и сохраняет прогресс при установке поверх предыдущего Defold APK.
