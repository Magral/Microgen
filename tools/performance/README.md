# Длительное воспроизведение нагрузки — архивная инструкция

> Этот инструмент и приведённая ниже процедура относятся к прежнему техническому прототипу. Они не являются средством измерения производительности текущей сборки Defold и не должны использоваться для заявлений об Android FPS.

## Требования прежней процедуры

Python 3.12 или новее, прежний игровой движок, а для автоматической нативной отрисовки — Xorg с фиктивным видеодрайвером, OpenGL/Mesa и доступный TCP-дисплей X11. Видеозапись не выполняется.

## Запуск из корня репозитория

```sh
python tools/performance/run_profile.py --commit 64a50cb --output /tmp/microgen-baseline --native
python tools/performance/run_profile.py --output /tmp/microgen-current --snapshots /tmp/microgen-baseline --native
```

Сценарий инструментирует временную копию проекта. Исходные файлы переданного рабочего каталога не изменяются. Параметр `--commit` извлекает указанную ревизию Git; без него используется текущая рабочая копия. Результаты включают JSON симуляции по этапам, снимки, JSON нативных этапов, JSON сцены с ограниченным числом объектов и журналы Xorg. Параметры `--source`, `--godot` и `--display` позволяют указать другую копию исходников, исполняемый файл или существующий дисплей. Режим `--render-only --native --snapshots /tmp/microgen-baseline` пропускает длительный прогон, если менялся только код отрисовки. Для нативных сравнений используются **одни и те же исходные снимки** через `--snapshots`; отдельно также измеряется длительный прогон каждой текущей версии.

Реальная симуляция выполняет 36 000 шагов с интервалом 1/60 секунды: десять игровых минут, а не десять минут реального времени. Отчёты формируются на отметках 0, 180, 360, 540 и 600 секунд. Seed 44; шесть органов третьего ранга (щупальца/кислота/заражение/след/деление/импульс); четыре адаптации третьего ранга (скорость/регенерация/броня/магнит); 10 миллионов HP; появление босса отключено только для профилирования; направление движения меняется каждые шесть игровых секунд. Паузы уровней пропускаются, очереди событий интерфейса и звука обрабатываются каждый кадр.

Нативные тесты выполняются при 1280×720 с совместимым рендерером, без ограничения частоты кадров движком и с отключённой запрошенной VSync. Для каждого исходного снимка на отметках 0/180/360/600 выполняются 60 прогревочных кадров и 180 измеряемых вызовов отрисовки, пока симуляция продолжается с частотой 1/60. Существующие массивы `impulse` в контрольных точках исправляются тестовым стендом, чтобы разрешить продолжение. Эффекты не сериализуются форматом снимка игры и поэтому создаются заново во время прогрева. Миникарта, HUD и сведение звука исключены из этого теста отрисовки мира; остальные игровые эффекты включены.

Замороженная сцена с ограниченным числом объектов содержит 28 заражённых врагов, 80 полей, 96 останков, 600 предметов, 200 выстрелов и 160 эффектов (80 меток урона и 80 эффектов токсичной колонии), расположенных рядом с игроком; выполняются 20 прогревочных и 60 измеряемых кадров. Это намеренно неблагоприятный сценарий, не отражающий обычную игру. Шаги симуляции пропускаются, чтобы сохранить точное количество объектов.

Счётчики JSON в микросекундах измеряют CPU-время построения на стороне скриптов, с отдельными этапами симуляции и отрисовки. CPU-время обновления нового ландшафта `update_world` измеряется отдельно. Кэшированные узлы ландшафта сохраняют нативные команды отрисовки и не перестраивают геометрию каждый кадр. Одноразовая подготовка сцены и первые отрисовки участков не входят в прогретые измерения. На llvmpipe растеризация, время шейдеров и поведение драйвера делают абсолютное время кадра непригодным для обещаний FPS на настольных или мобильных устройствах. Сравнивать следует CPU-измерения на одной и той же машине; перед принятием результатов проверять журналы на ошибки.

## Отдельный тест воды

`python tools/performance/profile_water.py SOURCE OUTPUT` копирует SOURCE во временный каталог, измеряет время обработки жидкости и отрисовывает фиксированную остановленную сцену воды. Для исходной версии следует использовать извлечённый архив Git; переданный каталог исходников не изменяется. Требуется прежнее настольное окружение с Xorg и движком. Видеозапись не выполняется.
