# Микроген

Офлайн 2D-рогалик для Android: амёба, поглощение ДНК, мутации и синергии.
Основной принцип — случайность и процедурная генерация.

## Первый перенос проекта

Загрузите в корень репозитория файл **Microgen-0.1.0-source.zip**:
[открыть загрузку файлов](https://github.com/Magral/Microgen/upload/main).

Исходный архив сохранён в ChatGPT:
[Microgen-0.1.0-source.zip](https://chatgpt.com/library?file_id=libfile_9b46557c47ac8191881042dad36fc53d&account_id=personal).

После коммита архива GitHub Actions автоматически:
1. Проверит и распакует исходники.
2. Сохранит файлы проекта в репозиторий.
3. Запустит проверки Godot и сенсорного управления.
4. Соберёт подписанный тестовый APK и сохранит его в результатах Actions и Releases.

До загрузки архива сборка находится в состоянии ожидания исходников.
Загрузка APK вместо архива исходников не подходит.

## Где скачать игру

[Сборки и проверки](https://github.com/Magral/Microgen/actions) ·
[Тестовые релизы](https://github.com/Magral/Microgen/releases)

Сохранённая исходная версия — 0.1.0. Изменения 0.2.0 с процедурной внешностью не следует считать перенесёнными, пока соответствующие файлы и проверки не появятся в этом репозитории.

Для обновлений используется вложенный в исходный архив тестовый Android debug-ключ. Это не ключ публикации в магазине. Приватные release-ключи хранить в репозитории не нужно.
