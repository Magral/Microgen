# Microgen · Defold

**Microgen** — Android-рогалик с автоматическими боями об эволюции амёбы в процедурном микромире. Игрок управляет организмом одним пальцем, а атаки выполняются автоматически. Рост, органы, мутации, пигменты, повреждения и поглощение формируют его развитие.

## Основа проекта

- **Движок:** Defold
- **Последний стабильный релиз:** [Defold 1.5.8](https://github.com/Magral/Microgen/releases/tag/defold-1.5.8)
- **Рабочая ветка:** `preview/defold`
- **Каталог игры:** `prototypes/defold`
- **Платформа:** Android, ARM64 (`arm64-v8a`), альбомная ориентация
- **Идентификатор приложения:** `org.magral.microgen.defold`
- **Минимальная версия Android:** API 26
- **Контрольное устройство:** Poco X8 Pro; игра также рассчитана на другие поддерживаемые Android-смартфоны и соотношения сторон.

## Игровой процесс и визуальное направление

- Процедурные биомы, организмы, угрозы, ресурсы и боссы.
- Органы, мутации и синергии, меняющие бой и анатомию.
- ДНК, биомасса, ядра наследия и органиум для развития.
- Поглощённая ткань становится частью организма и влияет на его пигменты.
- Живая полупрозрачная мембрана с ядром, волокнами, порами, сосудами, деформацией, ранами и восстановлением.
- Фрагменты погибших организмов сохраняют окраску и материальные свойства.

Визуальная целостность ткани и читаемость интерфейса — обязательные требования проекта.
